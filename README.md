# Twilio 10DLC Compliance Site

Simple GitHub Pages site with Privacy Policy and Terms of Service for Twilio 10DLC registration.

## Quick Setup

1. **Create a GitHub account** (if you don't have one): https://github.com/join

2. **Create a new repository**:
   - Go to: https://github.com/new
   - Name it: `twilio-compliance` (or whatever you want)
   - Make it **Public**
   - Check "Add a README file"
   - Click "Create repository"

3. **Upload these files**:
   - Click "Add file" → "Upload files"
   - Drag `index.html`, `privacy.html`, and `terms.html` into the upload area
   - Click "Commit changes"

4. **Enable GitHub Pages**:
   - Go to repository Settings → Pages (left sidebar)
   - Under "Source", select "main" branch
   - Click "Save"
   - Wait ~1 minute for it to deploy

5. **Get your URLs**:
   - Your site will be at: `https://YOUR-USERNAME.github.io/twilio-compliance/`
   - Privacy: `https://YOUR-USERNAME.github.io/twilio-compliance/privacy.html`
   - Terms: `https://YOUR-USERNAME.github.io/twilio-compliance/terms.html`

6. **Submit to Twilio**:
   - Paste those URLs into the Twilio 10DLC registration form
   - Done!

## Files

- `index.html` - Landing page with links
- `privacy.html` - Privacy Policy
- `terms.html` - Terms of Service

All files are minimal but compliant for a personal AI agent service.
