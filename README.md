# Twilio 10DLC Compliance Site
Simple GitHub Pages site with Privacy Policy and Terms of Service for Twilio 10DLC registration.

## Files
- `index.html` - Landing page with links
- `privacy.html` - Privacy Policy
- `terms.html` - Terms of Service

Intended for compliance for 10DLC sole proprietor registration for SMS/MSM usage of Twilio phone number for personal AI agent service.
